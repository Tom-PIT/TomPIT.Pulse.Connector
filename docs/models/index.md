# Models

Models define how source-system data is represented when integrating with Pulse.

Each model is designed for a particular industry or operational context and provides the entities, relationships, integration flow, and API guidance needed for that type of integration.

Models map industry-specific data into Pulse while allowing the platform to process information consistently across different domains.
