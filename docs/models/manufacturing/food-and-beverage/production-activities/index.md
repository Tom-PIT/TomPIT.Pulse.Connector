# Production activities

Production activities describe the work performed during Food & Beverage production, from incoming material lots and bulk processing through filling, packing, cleaning, and quality holds.

Register referenced master data and definitions before submitting activities that depend on them.

## Resources

| Resource | Description |
| --- | --- |
| [Lot](lot.md) | Records a traceable quantity of material received from a supplier, including optional lot analysis. |
| [Batch](batch.md) | Represents a bulk production step such as a cook, fermentation, or blend. |
| [Run](run.md) | Represents filling or packing production for a product on a production line. |
| [Planned use](planned-use.md) | Defines the resources a run, batch, or clean is expected to use. |
| [Stage](stage.md) | Represents a production step within a run and the machine that performs it. |
| [Clean](clean.md) | Represents a cleaning activity between two products on a production line. |
| [Hold](hold.md) | Represents a quality hold placed on finished stock while a decision is pending. |
