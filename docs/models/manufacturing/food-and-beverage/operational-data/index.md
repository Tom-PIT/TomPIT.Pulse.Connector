# Operational data

Operational data records what actually happened during Food & Beverage production.

These resources capture resource use, production output, measurements, equipment settings, production-line time, and discrete operational events.

## Resources

| Resource | Description |
| --- | --- |
| [Consumption](consumption.md) | Records ingredients, packaging, utilities, Labor, equipment, and other resources actually consumed. |
| [Output](output.md) | Records quantities produced, including good output, waste, downgrade, and reject quantities. |
| [Readings](reading.md) | Records measured values captured during production. |
| [Settings](setting.md) | Records commanded or configured process values. |
| [Line time](line-time.md) | Records intervals used to account for production-line availability and constrained or non-running time. |
| [Events](event.md) | Records discrete operational occurrences such as stoppages, deviations, waste, rework, or rejects. |
